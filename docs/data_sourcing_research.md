### LBox Open 판례 코퍼스 — 키워드 필터링 완료 (`data/raw/sources_research/lbox_open/`)

전체 원본은 `lbox/lbox_open`(HuggingFace, `precedent_corpus/train.jsonl`, **15만 건 / 1.16GB**, 승인 없이 공개 다운로드 가능, **라이선스 CC-BY-NC-4.0 — 비영리만 허용**, 졸업과제 용도는 문제없음)에서 스트리밍으로 받은 뒤, 원본(1.2GB)은 삭제하고 프로젝트에 필요한 부분만 3개 파일로 필터링해 남겼다.

| 파일 | 건수 | 크기 | 필터 조건 |
|---|---|---|---|
| `lbox_fraud_core.jsonl` | 534건 | 9.2M | 임대차+사기/편취, 전세보증금+편취, 신탁+임대차, 이중계약/이중임대, 임차권등기명령 |
| `lbox_deposit_dispute.jsonl` | 1,661건 | 19M | "임대차보증금...반환" 분쟁 |
| `lbox_protection_mechanism.jsonl` | 1,052건 | 15M | 우선변제권/대항력 쟁점 |

스키마: `{"id": int, "precedent": "판결문 전문 텍스트"}` (조 단위로 안 잘려있는 원문 그대로, Parser로 재파싱 필요).

**주의**: "전세사기"라는 단어 자체는 코퍼스에 0건 걸렸다 — 이 데이터가 그 표현이 사회적으로 통용되기 전 시기의 판결문 위주라 법원이 "사기죄"·"편취" 같은 법률 용어로만 서술하기 때문. `fraud_core` 샘플 확인 결과(예: id 809 — 선순위 전세권 미해지 상태에서 임차보증금 편취) 실질적으로는 전세사기 사건과 정확히 일치하는 내용이니 라벨링 시 문제 없음.

⚠️ **커밋 전 확인 필요**: 이 3개 파일 합쳐서 43MB — 지금 `.gitignore`에 안 걸려서 그냥 커밋하면 저장소가 커진다. git-lfs 쓸지, 아니면 데이터는 로컬/외부 스토리지에만 두고 `.gitignore`에 추가할지 팀에서 정하는 게 좋겠다.

## A. 기존 방법론 확장 (조정원/금감원 판정 사례) — 자동화 실패, 수동 필요

- **한국공정거래조정원 분쟁조정사건처리시스템** — https://fairnet.kofair.or.kr/user/exam/case/406/166/list.do
  - 목록 페이지에 **임대차/전세 사례는 현재 노출 안 됨** (광고대행·렌탈·통신기기 위주).
  - **자동화 시도 결과**: curl로 검색폼 POST 시도 → 405/세션 오류. 브라우저 자동화로 "임대차" 검색 버튼 클릭 시도(3회, 확실히 매치되는 "광고대행"으로도 테스트) → **검색 결과가 전혀 필터링되지 않고 항상 전체 목록만 표시됨**. 이 사이트의 검색 기능 자체가 자동화 클릭에 반응하지 않는 것으로 보임(JS 이벤트 바인딩 문제로 추정).
  - **사람이 직접 브라우저에서 검색해봐야 함** — 자동화로는 이 이상 확인 불가.
- **금융분쟁조정위원회 조정결정례** (금감원) — 기존에 즉시연금 2건 확보한 소스. 임대차는 금융분쟁조정위 소관이 아니라서 이쪽에선 전세/임대차 관련 사례는 안 나올 가능성 높음 (금융상품 분쟁만 다룸).
- **공정위 데이터포털** — https://www.fairdata.go.kr/ — 페이지 자체는 확인했으나 구체적 임대차 데이터셋 존재 여부는 직접 방문해서 카테고리 탐색 필요 (자동 조회로는 확인 안 됨).

## B. 정상 대조군(표준계약서) — 완료

- 국토교통부 부동산거래 전자계약시스템(irts.molit.go.kr) — 민간임대주택 표준계약서 서식. 포털 형태라 직접 방문 필요.

## C. 전세사기 특화 자료 — 제한적, risk_type 분류 재검토 필요

- **HUG 전세사기예방센터** (khug.or.kr/jeonse) — 확인 결과 **피해자 구제 절차(신청서 서식) 위주**, 계약서 조항이나 사례 원문은 없음. 데이터 소스로는 약함.
- **찾기쉬운 생활법령정보** (easylaw.go.kr) — 계약 이후 피해 유형 페이지 확인: "허위/하자 있는 계약", "대항력 상실" 등으로 분류. 대법원 2022.2.11. 선고 2021다283834(중개인 기망 편취, 임대인 사용자책임) 등 판례 인용.
  - **중요**: 이 유형들은 지금 프로젝트의 5개 `risk_type`(과도한 위약금·불명확한 수수료 등)과 **매핑이 안 됨**. `real_labels.md`에서 유선통신 사례를 억지 매핑으로 판단해 제외했던 것과 같은 문제가 재발할 것 — **전세사기 데이터를 쓰려면 risk_type 분류 확장이 선행돼야 함** (팀 논의 필요).

## F. Kaggle / HuggingFace 등 해외 오픈 소스 — 한국 특화는 사실상 없음

- **Kaggle**: CUAD(Atticus), Legal-Clause-Dataset, Indian Contract Clauses 등 전부 **영어권 계약서**. 한국 임대차/불공정약관 데이터셋은 검색되지 않음. 유일하게 걸린 한국 관련 항목은 "Korean Apartment Deal Data"인데 이건 부동산 실거래가(가격) 데이터라 계약 조항과 무관.
- **HuggingFace**: `mteb/UnfairTOSLegalBenchClassification`, `lex_glue` 등도 영어(EU 약관법 기준) 데이터. 국내 데이터 중 유일하게 의미 있는 건:
  - **LBox Open** (https://github.com/lbox-kr/lbox-open , HF: `lbox/lbox_open`) — **한국 판례 15만 건**, 승인 없이 즉시 다운로드 가능 (GitHub/HF 공개). 단, 일반 형사·민사 판결 코퍼스라 임대차/불공정약관만 걸러내려면 사건명·키워드 필터링 작업이 필요함. "판례 원문에서 임대차 관련 건 추출" 용도로는 AI Hub 승인 기다리는 동안 즉시 쓸 수 있는 가장 현실적인 대안.
- **공공데이터포털(data.go.kr)**: 검색 결과 불공정약관/임대차 분쟁조정 전용 데이터셋은 확인 안 됨 (계약·입찰 표준데이터 등 무관한 항목만 검색됨).

## 결론 — 우선순위

1. **AI Hub 71834 다운로드 신청 즉시 진행** (승인 대기시간이 병목이므로 최우선)
2. 대기 중 **LBox Open**에서 임대차/전세 키워드로 판례 필터링 스크립트 작성 → 무료·즉시 확보 가능한 유일한 대량 소스
3. 조정원 사이트에서 "임대차/전세/보증금" 수동 검색으로 A방식 건수 추가 확보
4. 법무부 표준계약서(다운로드 완료)로 정상 대조군 라벨 보강
5. 전세사기 데이터를 실제로 쓸지는 **risk_type 분류 체계 확장 여부를 팀 회의에서 먼저 결정**해야 함 — 안 그러면 지금처럼 매핑 억지로 인한 제외 사례가 반복됨
