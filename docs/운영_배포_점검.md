## 3. 운영 가드레일 (#174, 코드 반영 완료)

배포 URL은 심사 기간에 누구나 접근할 수 있다. 분석 1건이 약 282원이라,
누가 스크립트로 수천 건을 돌리면 크레딧이 말라 심사위원 접속 시 서비스가
죽는다. 세 가지로 막는다.

| 환경변수 | 기본값 | 하는 일 |
|---|---|---|
| `AGENT_SERVICE_TOKEN` | 없음(검사 안 함) | 백엔드 우회 직접 호출 차단. 미설정이면 검사하지 않아 로컬 개발과 호환된다 |
| `ANALYZE_RATE_PER_MIN` | 6 | 클라이언트별 분당 분석 호출 상한. 분석은 70~90초짜리라 정상 사용자는 넘길 일이 없다 |
| `DAILY_OUTPUT_TOKEN_BUDGET` | 0(무제한) | 일일 출력 토큰 상한. 도달 시 503과 함께 **"분석 결과를 받지 못했으니 안전하다는 뜻이 아닙니다"**를 알린다 |

`/health`가 이 상태를 노출하므로, 외부 모니터링이 "살아 있는가"가 아니라
**"분석이 가능한 상태인가"**를 감시할 수 있다.

```json
{"status": "ok",
 "guardrails": {"service_token_enforced": true, "rate_limit_per_min": 6,
                "daily_output_token_budget": 400000, "budget_remaining": 372100}}
```

## 4. 외부 모니터링 설정 (5분 간격)

UptimeRobot 무료 플랜으로 충분하다(5분 간격, 50개 모니터).

| 모니터 | URL | 유형 | 확인 문자열 |
|---|---|---|---|
| 프론트 | `https://halffifty.onrender.com` | HTTP(s) | — |
| 백엔드 | `https://halffifty-backend.onrender.com/health` | Keyword | `"status":"ok"` |
| 에이전트 | `https://halffifty-agent.onrender.com/health` | Keyword | `"status":"ok"` |

설정 시 주의:
- **Keyword 모니터로 둘 것.** 단순 HTTP 200만 보면 헬스체크는 200인데 분석은
  죽어 있는 상태를 놓친다.
- 알림은 SMS나 앱 푸시로. 메일만 켜 두면 새벽에 못 본다.
- Starter 전환 **후에** 등록할 것. Free 플랜에서는 모니터링 자체가 인스턴스를
  계속 깨워 두는 편법이 되는데, 그렇게 버티다 심사 중에 실패하면 더 나쁘다.

## 5. 심사 기간 일일 점검 (9/7 ~ 9/11)

하루 한 번, 1분이면 된다.

```bash
cd agent && python smoke_deployed.py          # 실제 분석까지 완주 확인
```

이 스크립트가 보는 것:
1. 3계층 생존
2. 콜드스타트 15초 초과 여부 (경고)
3. **실제 조항 하나를 분석해 판정까지 받는지** — 헬스체크만 200이고 분석이
   죽는 경우가 실제로 있다
4. 가드레일 비용 상한 잔여 — 소진돼 있으면 심사 중 거부가 난다
5. REST 응답에 방화벽 필드가 실려 오는지

크레딧을 아끼려면 `SKIP_ANALYZE=1`로 3번을 생략할 수 있지만, 하루 한 번은
분석까지 돌려 보는 편이 낫다. 조항 1건이라 원가가 무시할 수준이다.
