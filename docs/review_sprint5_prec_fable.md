# 검수 스프린트 5 추가 배치(prec 소비자 유형) — 10개 배치 231건 중 5건 통과 (골든셋 4행 반영)

> 같은 날 진행된 ftc 배치(`docs/review_sprint5_fable.md`, 240건·+1행)와 별도 세션에서 병행된
> 검수다. 두 배치를 합치면 스프린트 5는 471건 판정·골든셋 +5행이다.

> 절차는 `docs/review_sprint4_fable.md`와 동일: **제작 컨텍스트와 분리된 검수 컨텍스트**가 법제처
> OPEN API 판례 원문 XML을 재대조하며 반박을 시도한다. 이번 스프린트도 **Claude Fable 5가
> Claude Code 세션에서 직접 검수**했다 — API 크레딧 미사용, 배치별 별도 세션 10개로 컨텍스트 분리.
> 원문 접근 실패(보류)는 10개 배치 전체에서 0건이었다.

## 대상 범위

- 4차 이후 남은 미검수 중 **소비자 계약 유형·안전 경계 표본 기대 파일 우선 19개 파일 = 231건 판정**
  (판정 후 남은 미검수 **927건**)
- 배치 구성(10개): 약관유효 28 · 신의칙위반아님+해약금 17 · 위약금(약정 포함) 21 · 손해배상예정 25 ·
  위약벌 24 · 청약철회제한 26 · 자동갱신 A/B 39 · 생활서비스 7파일 29 · 렌터카·이사·골프 22

**결과: {'기각': 211, '자동기각': 15, '수정승인': 5} · 통과율 5/231 = 2.2%**
(수정승인 5건 중 1쌍은 동일 조항의 스윕 간 교차 표집이라 골든셋 신규는 **4행**)

> `split`은 전부 `train`으로 넣었다. **held-out(test) 배정은 사람이 정한다.**
> 같은 사건의 조항은 같은 split(누수 차단).

## 배치 관찰 요약 (재발 방지용)

- **sprint4 관찰 재확인**: 판례 전문 검색은 키워드와 무관한 형사·조세·노동·행정 사건과 B2B 분쟁을
  대량 유입시키고, "(이하 …라 한다)" 관용구 절단·판결 이유 서술 혼입이 기각의 최대 축이다.
  추출기 수정 없는 동일 경로 재스윕은 비효율이라는 결론도 동일.
- **동일 분쟁 체인 중복**: 위약벌 배치에서 3사건 체인(241731→241723→241625)과 심급 쌍(608513→607789)이
  각각 중복 표집됨 — 사건 사슬 필터 필요성 재확인.
- **교차 표집**: 2019가합52860 제10조 제1항이 신의칙위반아님·청약철회제한 두 파일에서 각각 통과 —
  스윕 키워드 간 dedup이 승인 단계까지 필요함을 처음 실측.
- **재추출 단서**: 241081(2023다202228) 원문에 은행 근질권 자동연장특약의 축자 인용과 약관법 §9(6)
  무효 부정의 명시 판단이 존재하나 후보 clause_text가 오추출이라 기각 — 재추출 가치 있음.
  237657(2019누38108)의 환불불가 문언("취소, 변경, 노쇼 시에는 총 예약 금액이 청구됩니다")도 동일.
- **판정 유보 없는 원문 확보**: law.go.kr OC=test 조회가 10개 배치 전부에서 안정적으로 동작 —
