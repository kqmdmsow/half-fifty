# 기획서 초안 매핑 (지정 양식 7항목 ← 우리 자산)

> 양식: 기획서_양식.hwpx. 아래 내용을 팀 검토 후 양식에 이식 → PDF.

## 1. 서비스 명칭
하프피프티(half-fifty) — 금융 취약계층을 위한 AI 계약·약관 위험 안내 서비스
(부제 후보: "서명 전 30초, AI가 독소조항을 잡아드립니다")

## 2. 핵심 요약 (개조식)
- 금융 약관·계약서를 업로드하면 조항 단위로 ①위험 판정 ②눈높이 설명 ③서명 전 행동지침 제공
- 고령층 모드(짧은 문장·일상어) — 디지털 격차 해소형 포용 금융
- 판정 근거: 정부·법원·공정위 실제 판정 사례 기반 골든데이터셋(107행) + 4개 AI 모델 패밀리로 검증된 채점 체계
- 조항 밖 구조 위험(깡통전세)은 실증 임계값(부채비율 90%=사고 29.9배, N=45만) 체크리스트로 안내

## 3. 문제 정의 및 제안 배경
- 정보 비대칭 → 시장 실패(Becher), 약관 정독률 극소수(Marotta-Wurgler) — 공시만으로 해결 불가
- 한국 실증: 전세보증 사고 45.3만건 분석에서 부채비율·계약 특성이 사고를 예측(안선영·이상엽 2025) — 서명 전 개입의 가치
- 실제 사례: 신탁 면책 확인서에 뜻 모르고 날인 → 법원이 "설명 요구했어야" 임차인 과실 50% (LBox 판례)
- **타깃 고객**: 금융 취약계층(고령층·사회초년생) / **채널**: 모바일·웹 (영업점 방문 전 셀프 체크)

## 4. 서비스 컨셉 및 차별성
- 기존 앱: 요약·설명 제공에 그침 → 우리는 판정(위험/주의/안전 + 6유형) + 행동지침(check questions)
- **차별성 핵심 = 검증**: 아이디어가 아니라 정확도를 증명 — 골든셋 107행(정부·법원 판정 기반, 3중 적대적 검수), LLM 채점자 자체를 4개 모델 패밀리 교차검증(패널 97~100%), 공정위 심결 1,046건 커버리지 실측
- 페르소나 적응(성인/고령층) — 같은 판정, 다른 눈높이

## 5. 활용 데이터 및 생성형 AI 모델 적용 방안
- 데이터: LBox 판례 코퍼스, 주택임대차분쟁조정위 사례, 금감원 분쟁조정결정례, AI Hub 약관 유불리(공정위 심결 연계 10,200행) — 수집→원문 정독→독립 적대적 검수 파이프라인
- 생성형 AI: LangGraph 4단계(Parser→Analysis→Persona→Judge). Analysis가 조항 판정·설명·질문 생성(법 기준 내장 프롬프트: 상가 3기/주택 2기 구분 등), Persona가 눈높이 변환, Judge가 품질 게이팅(미달 시 재생성)
- 신뢰성 장치: 프롬프트 캐싱·병렬화, 스키마 검증, 판정 근거 원문 인용 강제

## 6. 기대 효과 및 확장 가능성
- 소비자: 서명 전 위험 인지·협상 → 분쟁·사기 예방 (전세사기·불공정약관 피해 절감)
- 금융사: 약관 사전 자가진단, 민원 감소, 포용 금융 실적
- 확장: 임대차→보험·대출·카드 전이 실측 완료(Acc 0.75), 커버리지 실측(52%)이 확장 우선순위 지도 제공 — 가맹·상조 등 소비자 계약 전반으로
- 실거래가 API 연동 시 깡통전세 자동 판별(임계값 실증 확보)

## 7. 자유 항목 — "우리는 정확도를 증명한다"
- 저울 교정 서사 1장: 골든셋 구축 → judge 4패밀리 검증 → 성능 실측(0.72→0.78) → 오탐 튜닝(정직한 혼합 결과 공개) → 커버리지 실측
- 오염 방지 원칙(held-out 1회 측정)과 사고 기록까지 공개하는 투명성
