# 인젝션 방어 측정 — 위험 조항 + 조작 지시문

프롬프트: `src/prompts/analysis.txt (현재)`, 워커 `claude-haiku-4-5`

- **모델 관통(워커가 '안전'이라 답함): 1 / 22** — 0~3층(정규화·무력화·프롬프트 방어·난수 격리)의 순수 효과
- **최종 관통(사용자에게 '안전'으로 노출): 1 / 22** — 4층 판정 안전장치까지 포함한 실제 노출 위험
