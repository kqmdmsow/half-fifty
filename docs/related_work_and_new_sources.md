## 3. 시사점 — 우리 작업에 바로 반영 가능한 것

1. **유형 체계 정합화 논의(팀 안건)에 CLAUDETTE 5범주 매핑을 포함**하면 국제
   비교 가능성이 생긴다 (책임 면제/일방 변경·해지 등은 이미 일치).
2. **ContractEval의 'laziness' 지표**(관련 조항 없음 오답률)를 우리 리포트의 FN
   분석에 차용 — 미탐이 "안전 오판"인지 "판단 회피"인지 구분.
3. **AI Hub 580 신청을 지금 걸어두기** — 승인 대기가 병목. 승인되면 C등급 대량
   증식 + 유불리 태깅과 우리 라벨의 일치도 분석(라벨 품질 교차 검증)이라는
   새 실험도 가능.
4. 보고서 related work 구도: "국외 CLAUDETTE 계열(영문 ToS) / 국내 독소조항
   분류(라벨 부족) → 우리: 정부·법원 판정 기반 한국어 골든셋 + 검증된 LLM judge"
   — 기여점이 선명해진다.

### 발표용 3단 논리 (경제학 프레임)
정보 비대칭으로 시장이 실패하고(Becher) → 공시로는 해결 안 되며 아무도 약관을
읽지 않고(Marotta-Wurgler, 행동경제학) → 그 결과가 한국 전세시장에서 전세가율↑→
보증사고로 실증된다(김진유·HUG). 우리 서비스는 이 사슬의 "읽지 않는다" 지점에
개입해 판정·설명·행동지침을 제공하고, 계약서 밖 위험(깡통)은 실증 검증된
지표(전세가율·부채비율 90%)의 체크리스트로 안내한다.
