# 시각장애인은 실제로 계약을 어떻게 체결하는가 — 조사와 서비스 함의

> 2026-08-19, 동훈. #82(접근성) 후속 질문 "시각장애인이 버튼을 클릭하며 쓰는 게
> 가능한가? 애초에 계약 체결은 어떻게 하는가?"에 대한 조사 기록.
> 기획서(#54) 포용성 문단과 #82 완료 판단의 근거 자료.

## 1. 전제 교정: 시각장애 = 전맹이 아니다

- 시각장애는 스펙트럼: 전맹(빛 지각 불가)은 소수, 다수는 **저시력**(흐릿함,
  시야 결손, 명암 구분 곤란). → 저시력은 **고대비·확대**로 화면을 "보며" 쓰고,
  전맹은 **스크린리더**(키보드/제스처 순회 + 음성 낭독 + Enter 실행)로 쓴다.
- "버튼 클릭"의 실제: 전맹 사용자는 마우스로 보지 않는다. Tab/스와이프로 요소를
  이동하면 리더가 "계약서 분석 시작, 버튼"이라 읽고, Enter/더블탭으로 실행한다.
  → 시맨틱 버튼·aria-label·포커스 이동(#123)이 그 전제 조건.

## 2. 실제 계약 체결 과정 (조사 결과)

### 부동산 계약 (임대차·매매)
- **관행**: 공인중개사가 계약서·중개대상물 확인설명서를 **구두로 설명**
  (공인중개사법 §25 확인·설명 의무 — [법령](https://www.law.go.kr/%EB%B2%95%EB%A0%B9/%EA%B3%B5%EC%9D%B8%EC%A4%91%EA%B0%9C%EC%82%AC%EB%B2%95)).
  시각장애인은 통상 가족·활동지원사 **동행 + 중개사 대독 + 서명(또는 무인)**.
  국토부 [부동산거래 전자계약시스템](https://irts.molit.go.kr/usr/cmn/main/home/RtecsHelp.do)이
  존재해 전자문서 입수 경로는 늘어나는 중.
- **발견(공백)**: 시각장애인의 부동산 계약 체결 실태에 대한 공개 연구·통계가
  검색으로 거의 확인되지 않음 — 이 공백 자체가 "대독 의존이 관행이며 검증
  수단이 없다"는 방증. 기획서에 '연구 공백'으로 인용 가능.

## 3. 구조적 문제 — 우리가 조준할 지점

**대독·대필 구조의 본질적 취약점: 읽어주는 사람이 이해관계자다.**
- 은행 직원·공인중개사·임대인·판매자가 읽어주는 내용이 실제 문서와 같은지
  시각장애인 본인이 **독립적으로 검증할 수단이 없다**.
- 인권위 진정 사례처럼 "대필자를 지정"당하는 상황은 정보 비대칭의 극단.
- 비장애인 동행인(가족 등)이 있어도 법률 문해력이 없으면 위험 조항을 못 걸러냄
  — 이건 조목조목이 이미 푸는 문제와 동일.

## 4. "진짜 해결 가능한 대책" — 서비스 버전 설계

### 조목조목의 역할 재정의 (과장 금지 원칙 유지)
"시각장애인 완전 지원" ❌ → **"대독에 의존하지 않는 독립적 계약 검증 수단"** ⭕
계약 *체결 절차*(서명·본인확인)는 은행·중개사의 법적 의무 영역이고, 우리는
그 **앞단계 — '이 문서에 실제로 뭐라고 쓰여 있고 무엇이 위험한가'를 본인
귀로 직접 확인**하는 단계를 맡는다.

### 2025~26 정책과의 접속점 (기획서 핵심 논리)
금융위 정책이 만들고 있는 인프라는 "**계약서류를 텍스트 파일로 제공 →
시각장애인이 직접 음성변환으로 확인**"까지다. 즉 은행이 주는 것은 **원문
접근**이고, 그 원문을 **이해와 위험 판단으로 바꿔주는 도구는 공백**이다.
조목조목의 '텍스트 붙여넣기 → 조항별 위험 분석 → 쉬운 설명 → 전체 낭독'
경로는 이 정부 인프라의 **바로 다음 단계에 정확히 접속**한다 — 은행이
텍스트 파일을 주는 순간, 그것이 우리 서비스의 표준 입력이 된다.
반면 **부동산 계약은 이런 인프라 자체가 없어**(정책이 금융권 중심)
대독 의존이 그대로 남아 있다 — 임대차가 주 도메인인 우리에게 더 큰 공백.

### 실사용 시나리오 3종 (현재 코드로 가능한 것)
1. **사전 검토**: 전자문서·문자로 받은 계약 내용 붙여넣기(주 경로, 기존 명시)
   → 분석 → 전체 낭독(#123) → 확인 질문을 계약 자리에서 사용
2. **현장 교차 검증**: 동행인이 계약서 사진 촬영(촬영은 조력 필요 — 과장하지
   않음) → OCR → 본인이 낭독으로 직접 확인 → "중개사가 설명한 내용과
   문서가 같은가"를 제3의 귀로 대조
3. **저시력**: 고대비 + 글자 확대 + 조항별/전체 낭독 병용
