# 참고문헌 보관소 (경제학·실증 연구)

서비스의 문제 정의와 구조적 위험 안내(깡통전세 체크리스트)의 실증 근거 문헌.
원문 PDF는 오픈액세스/공개 보고서만 보관 (라이선스 준수).

## 1. 안선영·이상엽 (2025) 「전세보증금 미반환에 영향을 미치는 주요요인 연구」
- 주택금융연구 9(2), 47-68. DOI 10.52344/hfr.2025.9.2.47. **CC BY-NC 4.0 오픈액세스**
- 데이터: 2019~2024(72개월) 수도권 전세보증 **453,122건** (시장 점유율 89% 보증기관),
  이항로짓 분석
- **핵심 수치 (Exp(B), 전체모형·1% 유의)** — 위험 요인:
  | 요인 | 승산비 |
  |---|---|
  | **부채비율 90% 이상** (vs 60% 미만) | **29.9배** |
  | 부채비율 80~90% | 5.5배 |
  | 연립다세대 (vs 아파트) | 5.8배 |
  | 전문가(감정평가) 가격산정 | 4.8배 |
  | 보증금 대비 대출 비율 | 4.8배 |
  | 법인 임대인 | 3.6배 |
  | 다주택자 임대인 | 2.5배 |
  | 오피스텔 | 2.3배 |
  | 인천 / 경기 (vs 서울) | 7.0 / 3.6배 |
  완화 요인: 보증부월세 0.28, 전세대출 이용 0.26, 선순위채권 0.48, 등록 임대사업자 0.96
- 사고 집단 평균 부채비율 96.1 vs 정상 72.8 (t=177.7)
- **우리 활용**: 구조적 체크리스트의 항목·임계값 실증 근거
  (`data/jeonse_risk_reference.json` 참조). "감정평가서 기반 시세는 오히려 위험
  신호"라는 비직관적 발견도 안내 문구 가치.

## 2. 탄탄주택협동조합 연구팀 (2025) 「사회적 경제 방식을 활용한 전세사기 피해 회복 모델 분석」
- SVS 인사이트 10호 (공개 보고서). 전세사기 피해 회복 사례 분석 — 피해 이후
  단계의 맥락 자료 (우리 서비스는 예방 단계 개입임을 대비시키는 용도).

## 3. 링크만 보관 (페이월/라이선스)
- Marotta-Wurgler, "Does Anyone Read the Fine Print?" — 표준계약 정독률 실증(극소수).
  J. Legal Studies. 서비스 존재 이유의 고전 실증.
- Becher, "Asymmetric Information in Consumer Contracts" (SSRN 1016010) — 정보 비대칭
  시장 실패 논거.
- "Behavioural Economics in Unfair Contract Terms" (J. Consumer Policy, 2011) —
  공시만으로 해결 불가 → 판정+행동지침 설계의 정당화.
- HUG 담보인정비율 100%→90% 인하(2023) 보도 — 부채비율 90% 초과 = 보증사고
  금액 ~70%, 사고율 3배 (정책 실무의 임계값).
