# 실물 조항 정답지(real_clause_labels.csv) 평가 결과

`data/real_clause_labels.csv`(정부/법원 판정 기반 44건 — hldcc·LBox·AI Hub 자연발생 템플릿)에 대해 `analysis._analyze_clause()`를 직접 호출한 결과. Parser/Persona/Judge 없이 Analysis 로직만 단독 평가.

> **모델 안내**: 이 결과는 2026-07-26/27 Gemini 전환 실험 중 `gemini-flash-lite-latest`
> 기준으로 측정됐다. 이후 팀 리뷰로 기본 모델이 Claude로 복원됐으므로, 이 수치는
> **현재 기본값(Claude)의 베이스라인이 아니라 Gemini 실험 당시의 기록**이다.
>
> **[2026-07-27 베이스라인 정정 확정]** 2026-07-26에 낸 최초 수치(Precision 0.79/Recall
> 0.81/Accuracy 0.75, 44건 전체 기준)는 **오염된 값이었다** — Train/Val로 이미 지정된 4건이
> 섞여 있었다. `split` 컬럼을 추가해 분리한 결과, **진짜 held-out인 Test 40건 기준 공식
> 베이스라인은 Precision 0.73 / Recall 0.83 / Accuracy 0.72**다 (`gemini-flash-lite-latest`,
> 2026-07-27). 이 정정된 수치를 최초 베이스라인으로 삼는다 — 지난번과 마찬가지로 **이 시점에서는
> 프롬프트를 고치지 않고 그대로 기록만** 한다(오염 방지 원칙은 계속 유지). 다음 개선 시
> Train(3건 + 자작 3문서)/Val(1건 + 자작 3문서)로 튜닝 후 이 Test 40건엔 1회만 재실행.
>
> 모델을 더 강한 것(`gemini-flash-latest` 등)으로 바꾸는 것은 정답을 들여다보고 고치는 게
> 아니라 정당한 아키텍처 선택이라 오염이 아님 — 이건 언제든 재시도해도 된다.

**중요**: 이 중 4건(광고대행/신발도매/즉시연금2017-17/바로연금보험2018-8, `data/real_labels.md` 출처)은 `docs/clause_level_dataset_and_split.md`에서 이미 Train/Val로 지정된, 프롬프트 튜닝 이력이 있는 데이터다. 이 4건을 섞어서 낸 수치는 공정한 held-out 평가가 아니므로, **아래 'Test 전용(40건)' 표만 공식 베이스라인으로 취급**한다. Train/Val 결과는 참고용으로만 병기.
