> 절차는 `docs/review_sprint4_fable.md`와 동일 원칙: **제작 컨텍스트와 분리된 검수 컨텍스트**가 공정위 결정문 원문 XML(law.go.kr FtcService)을 재대조하며 반박을 시도한다. 이번 스프린트도 **Claude Fable 5가 별도 배치 세션 12개로 직접 검수**했다 — API 크레딧 미사용(law.go.kr 공개 XML만 사용). 원문 접근 실패(보류 사유)는 12개 배치 전체에서 0건이었다.

## 대상 범위

- 대상 파일(1개): `data/staging/candidates_ftc_불공정약관조항.csv` 전체 297행 중 **12개 배치 = 240행 판정** (행 1~140 · 161~240 · 261~280)
- 이 파일 잔여 미검수 **57건**(행 141~160 · 241~260 · 281~297), 판정 후 전체 스테이징 잔여 미검수 **1,158건**(1,398 − 240)

**결과: {'기각': 155, '자동기각': 84, '수정승인': 1} · 통과율 1/240 = 0.4%** (스프린트 4 실측 3.1%보다도 낮음 — ftc 시정권고서 계열의 구조적 한계가 원인: '약관조항' 표가 예외 없이 `<img flDownload>` 이미지로만 존재해 조항 축자 문언이 XML 텍스트에서 탈락. 12개 배치에서 원문 XML 수십 건을 전수 실측한 결과 텍스트형 약관조항 표는 0개, 심사의견은 전부 '~것으로 규정하고 있다' 간접화법 서술)

> `split`은 `train`으로 넣었다. **held-out(test) 배정은 사람이 정한다.** 통과 1건 단일 사건이라 split 누수 이슈 없음.

## 배치 관찰 요약 (재발 방지용)

- **ftc 시정권고서의 구조적 병목**: 2008~2011년대 시정권고서는 '가. 약관조항' 표가 전부 스캔 이미지(`<img flSeq=…>`)라 조항 축자 문언이 XML에서 탈락 — 12개 배치 전체에서 텍스트형 조항 표 0개. `clause_text_candidate`가 채워진 행도 예외 없이 공정위 심사의견의 간접화법 서술('~것으로 규정하고 있다') 절편으로 판명. 이 경로에서 수확하려면 flDownload 이미지 OCR 파이프라인이 필요
- **따옴표 직접 인용만이 통과 신호**: 유일한 통과(985 코인네스트)는 FTC가 검토의견에서 조항 문구를 따옴표로 직접 인용한 사례. 반면 따옴표 인용이 있어도 술부 없는 조건절 단편(8645 해제조항, 10661 위약금 명사구)은 조항 전문 확정 불가로 기각 — '완결된 조항 문장 단위의 따옴표 인용' 여부를 선별 단계에서 걸러야 함
- **dedup 접두어 변형**: '변호사 권두섭 등 15개 사업자' 사건이 후보 사건명에서 '변호사' 접두어만 탈락해 startswith 자동기각 그물을 빠져나감(행 27~40 수동 기각) — 직함·법인격 표기 차이를 고려한 사건명 매칭 필요
- **일반명 사건명의 기계적 자동기각**: '불공정약관조항에 대한 건'처럼 일반명인 사건명은 dedup 절단 사건명과 기계적으로 startswith 일치(행 85~88) — 실제 별개 사건일 가능성이 있으나 규칙대로 자동기각 처리했음을 명기
- **사건 단위 복제 행**: 동일 시정권고의 사업자별 복제(권두섭 15부), 동일 문서의 이중 추출(8745·10971 등)이 다수 — 스테이징 생성 단계에서 사건·조항 단위 dedup 강화 권고
