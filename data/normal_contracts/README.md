# 정상 계약서 오탐(FP) 벤치마크 코퍼스

> 목적: "위험을 심지 않은, 기관이 제정·공표한 표준 양식"만 모아 문서 단위
> 오탐율을 측정한다 (`agent/eval_normal_fp.py`). 골든셋의 조항 단위 안전
> 라벨과 달리, **실사용 흐름(파서 분할 → 조항 분석) 그대로** 전체 문서를
> 통과시켜 "정상 문서를 넣었을 때 위험/주의가 몇 건 뜨는가"를 본다.
>
> 라벨 전제: 제정 기관(법무부·국토부/공정거래위원회)이 공표한 표준 양식
> 원문이므로 **전 조항 기대값 = 안전**. 이는 기존 안전 라벨과 동일한 전제다
> (data/real_labels.md의 예금거래기본약관 항목 참조). 단, 표준 양식에도
> 의무·제한 조항(원상회복, 연체 해지 등)은 존재하므로 '주의' 판정이 전부
> 무의미한 오탐은 아니다 — 리포트가 판정별 근거를 남겨 사람이 재검수한다.
